# 🤖 Robot Path Demo

A simple robot pathfinding simulation that shows a robot moving step-by-step from a start position to a goal, avoiding obstacles on an 8x8 grid.

## 🧠 Features

- 8x8 grid with obstacle placement
- Custom start and goal input
- Visual output of the robot's path
- Step count at the end
- Clean terminal-based output using Python
