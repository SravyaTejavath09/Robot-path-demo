# 🤖 Robot Path Demo

A simple robot pathfinding simulation that visualizes a robot moving step-by-step from a start position to a goal, navigating through an 8x8 grid while avoiding obstacles.

---

## 🧠 Features

- 8x8 grid-based environment  
- Custom start and goal input  
- Visual terminal output with robot, obstacles, and goal  
- Step count display  
- Reads grid from `custom_env.txt` file  
- Python implementation with clean and understandable logic

## 🚀 How to Run
Clone the repository (for others who want to try it):
git clone https://github.com/SravyaTejavath09/Robot-path-demo.git

Navigate to the project folder:
cd Robot-path-demo

Run the Python file:
python main.py

Make sure custom_env.txt is present in the same directory.
